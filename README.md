# 🐍 Snake Water Gun Game

A Python command-line game based on the classic Snake-Water-Gun (similar to Rock-Paper-Scissors).

## 🎮 How to Play

Run the script and enter your choice:
- `s` → Snake
- `w` → Water
- `g` → Gun

The computer picks randomly, and the winner is decided instantly!

## ▶️ Run
```bash
python snake_water_gunn_game.py
```

## 🔁 Rules

| You   | Computer | Result |
|-------|----------|--------|
| Snake | Water    | You Win |
| Water | Gun      | You Win |
| Gun   | Snake    | You Win |

## 🛠️ Tech Stack
- Python 3
- `random` module

# 🔢 Number Guessing Game

A Python CLI game where you guess a randomly generated number between 1 and 100.

## ▶️ Run
```bash
python main.py
```

## 🎯 How It Works

1. The program picks a random number (1–100)
2. You enter guesses
3. Get hints: *"Guess Higher"* or *"Guess Lower"*
4. Win when you guess correctly — your total attempts are displayed!

## 🛠️ Tech Stack
- Python 3
- `random` module
